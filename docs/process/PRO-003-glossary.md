# Glossary

Shared vocabulary. Using these terms precisely in conversation and code prevents an enormous amount of confusion later. **Player-facing** terms appear in-game; **internal** terms are for us.

| Term | Facing | Meaning |
|---|---|---|
| **She / the Wyrm** | Player | The hoard-dragon patron. Immobile, ancient, hungry. Grants power for tribute. |
| **The Bound** | Player | Anyone in pact with her, including the player and other players' echoes. |
| **Run** | Both | One descent, ~15–30 min. Ends in extraction or death. |
| **Life** | Both | One pact, spanning many runs. Ends at death. Holds skill tree, stash, rank. |
| **Lineage** | Both | All lives across a save. Holds knowledge, maps, contacts, world scars. Never lost. |
| **Legacy** | Player | The ≤3 things She remembers across death. Chosen at the death screen. |
| **Boon** | Player | Meta-currency earned by tributing extracted loot. Spent on Aspects. |
| **Tribute** | Player | Loot given to Her. Converts to Boon; satisfies Tithe. |
| **Tithe** | Player | Her escalating demand, scaling with Boon spent. The counter-pressure to power creep. |
| **Pact Rank** | Player | Tier of the pact. Gates Aspect nodes; drives Tithe. |
| **Aspect** | Player | One of five skill paths: Hoard, Cinder, Scale, Wing, Maw. |
| **Keystone** | Player | Build-defining node. One active at a time. Always has a real drawback. |
| **Scar** | Player | A permanent-for-this-life penalty from a wounded extraction or a bad choice. |
| **Clamor** | Both | Noise value. Emitted by actions and carried loot; drives aggro and the Hunt. |
| **The Hunt** | Player | The escalating pressure phase. Introduces the Hunter. |
| **Hunter** | Player | Unkillable (at first) pursuer that tracks Clamor. |
| **The Sealing** | Player | Extraction points closing one by one as the Hunt escalates. |
| **Cache** | Player | Loot hidden in the dungeon for retrieval on a later run. |
| **Contract** | Player | A run-scoped objective from a faction. 2–4 active. |
| **Whisper** | Player | An opportunistic objective found mid-run. Short, expiring. |
| **Complication** | Internal | The parameter that makes a generated contract feel authored. |
| **Glitter / Gear / Relic** | Both | Loot classes: tribute-only / utility-only / both. |
| **Grave-goods** | Player | Cursed high-value loot whose owner pursues you. |
| **Class / the Sworn** | Player | One of six archetypes, chosen at the start of a life. Grants a unique verb, a Rite branch, and access to 3 Aspects. |
| **Rite** | Player | A class-only skill branch (~7 nodes). Nobody outside that class can take them. |
| **Ember** | Player | The piece of her fire in each of the Bound. Drops on death in co-op; a friend can carry it out to save your life. |
| **Downed** | Player | Zero health but not dead. Crawling, revivable by an ally. |
| **Vörðr** | Player | Ward-spirit. What you become on death — a ghost who keeps playing, then chooses to wait for rescue or return with nothing. |
| **Stave** | Player | A Bound's rune-stick at the Threshold, notched with what they have given her. The game's only public tally, and deliberately not a table. |
| **The Lair** | Player | The hub as a whole — Chamber plus Threshold (ADR-021). |
| **Your Chamber** | Player | Private, local, never networked. Her, your hoard, the tree, the stash, the Legacy screen. Nobody else ever enters it. |
| **The Threshold** | Player | The mouth of the mountain. The shared, networked hub — Bound camp, Ashen Lodge, contract board, forge, the Descent. |
| **The Deep** | Player | The dungeon collectively. |
| **Delvings / Barrow-Fields / Sunken Wood** | Player | The three biomes. |
| **Ashen Lodge / Deep-Kin / Silent Choir** | Player | The three factions. |
| **Húskarl** | Player | Shield-Sworn. Endures. Scale · Cinder · Hoard. |
| **Völva** | Player | Seeress. Foresees. Maw · Wing · Cinder. |
| **Skald** | Player | Song-Speaker. Empowers, and is deliberately loud. Cinder · Hoard · Scale. |
| **Úlfheðinn** | Player | Wolf-Coat. Breaks through, cannot retreat. Cinder · Maw · Scale. |
| **Veiðimaðr** | Player | Stalker. Never seen. Wing · Hoard · Maw. |
| **Haugbrjótr** | Player | Mound-Breaker. The tomb robber. Hoard · Wing · Scale. |
| **Room module** | Internal | Hand-authored level chunk assembled by the generator. |
| **⟨tune⟩** | Internal | Marks a placeholder number awaiting playtest. |
