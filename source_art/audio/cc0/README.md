# CC0 source recordings

The takes `build_foley.py` cuts the game's recorded foley from (ADR-326).
Everything here is **Creative Commons Zero** — public domain, usable in
commercial work, no attribution required. Each pack's own `License.txt` sits
beside its files.

Credited although CC0 does not ask for it: thank you, Kenney, PagDev, artisticdude, bonebrah and AntumDeluge.

Only the takes the build uses are kept. To add a sound, add its source here
with its pack's licence and name it in `build_foley.RECORDED`; nothing here
is loaded by the game directly.
